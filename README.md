# IO NATALL&A — website

Portfolio and shop for the painter IO NATALL&A (Natalja Kossareva), Tallinn, Estonia.

- `index.html` — the whole site (pages, artwork data, cart, legal pages). Artwork texts and availability are in the `SERIES` list near the top of the script.
- `img/` — artwork images.

Hosted with GitHub Pages. Orders and questions are delivered to the artist's email through FormSubmit; the first message after launch sends an activation email that must be confirmed once.
